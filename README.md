# Task Manager App

Simple Task Management Web Application built using React.js, Node.js, Express.js, MongoDB, and JWT Authentication.

---

## Features

- User Signup & Login
- JWT Authentication
- Create Task
- Delete Task
- Toggle Task Status
- Filter Tasks
- Responsive UI

---

## Tech Stack

### Frontend
- React.js
- Axios
- React Router DOM

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

---

## Run Project

### Backend

```bash
cd backend
npm install
npm run dev
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

---

## Environment Variables

Create `.env` inside backend folder:

```env
PORT=5000
MONGO_URI=your_mongodb_url
JWT_SECRET=mysecretkey
```
